# Muster

Muster organises the skills Claude Code has on your Mac. It finds them, shows them in one place, and checks them for duplicates and conflicts. Nothing leaves your Mac.

Install it:

```bash
curl -fsSL https://muster.is/install.sh | bash
```

This repository holds Muster's releases. GitHub Pages serves it at [muster.is](https://muster.is). The source lives in a private repository.
