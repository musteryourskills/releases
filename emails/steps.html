Muster is ready for you. It organises the skills Claude Code has on your Mac: it finds them, shows them in one place and checks them for duplicates and conflicts.

✓A 23 MB download ✓No account ✓Nothing leaves your Mac
 
1
 Start here

Install it with one line

Paste it into Terminal on your Mac. It downloads Muster, checks the download and puts muster in ~/.local/bin. No admin password.

On your phone? Open this email on your Mac and paste the line there.
 
curl -fsSL https://muster.is/install.sh | bash

Needs Claude Code.
macOS, Apple silicon or Intel.
Copy it on muster.is
 

Then, in a new Terminal window

2

Sort your skills in your browser

Every skill on one page, in folders your Claude Code suggests. The files never move, and the page never goes online.

muster open
3

Check them with Claude Code

Your own Claude Code finds the skills that conflict or repeat each other. It runs on your plan, with no API key, and nothing changes until you say so.

muster check
