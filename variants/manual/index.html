You’re in

Welcome to Muster.

You’ve been let in off the waitlist, so Muster is yours to try. It organises the skills Claude Code has on your Mac: it finds them, shows them in one place, and checks them for duplicates and conflicts.

Install

Paste it into Terminal on your Mac

curl -fsSL https://muster.is/install.sh | bash
Downloads
Muster for your Mac’s chip, about 23 MB
Checks
The download against its checksum
Puts it in
~/.local/bin/muster
PATH
Adds ~/.local/bin to it
Asks for
Nothing. No admin password, no Gatekeeper prompt.

02Start here

The installer ends with these three. Run them in Terminal.

  • muster open

    See your skills on a page in your browser

  • muster

    List them here in the terminal

  • muster --help

    Everything else Muster can do

First run
The first muster open counts your skills. Your Claude Code suggests up to eight folders, and Autosort files the skills into them: 137 skills take about 7–15 seconds. Then press Get started.
Command not found
This window may not know muster yet. Use ~/.local/bin/muster open here. In new terminal windows, plain muster works too.

03Commands

Everything else. muster --help lists them too.

CommandWhat it does
muster checkCheck for conflicts and duplicates, found by your Claude Code
muster show <skill>Show one skill
muster move <skill>… <folder>Put skills in a folder. The files don’t move.
muster label <skill> <label>…Give a skill one or more labels
muster discover [words]Find public skills on skills.sh
muster add <owner/repo/skill>Add a public skill
muster --project <dir>Include the skills in a project’s .claude/skills
muster --jsonPrint the output as JSON

04What stays on your Mac

All of it. Nothing leaves your Mac.

Account
None. There are no Muster servers.
The check
Runs through your own Claude Code, claude -p, on your subscription. No API key.
The page
muster open serves it on 127.0.0.1. It’s never online.
Folders and labels
Muster’s own, kept in ~/.muster/
Skill files
Never move

05Requirements

Mac
macOS, on Apple silicon or Intel
Claude Code
Installed. Muster uses it for the check and Autosort.

06Update and remove

  • muster update

    Install the latest version

  • muster --version

    Your version, and whether a new one is out

  • rm -rf ~/.local/bin/muster ~/.local/share/muster ~/.muster

    Remove Muster and all it keeps in ~/.muster: folders, labels, and any skills you archived. Restore those first. Skill files in use stay where they are.
