You’re in,

Three steps to sorted skills.

You’re off the waitlist, and Muster is ready for you. It organises the skills Claude Code has on your Mac: it finds them, shows them in one place, and checks them for duplicates and conflicts.

  • A 23 MB download
  • No account
  • Nothing leaves your Mac
  1. 1 Up next

    Install it with one line

    Paste it into Terminal. It downloads Muster for your Mac, checks it against its checksum and puts muster in ~/.local/bin. No admin password.

    curl -fsSL https://muster.is/install.sh | bash

    macOS, Apple silicon or Intel

    zsh

    ~ % curl -fsSL https://muster.is/install.sh | bash

    Downloading Muster 0.45.0 for arm64 Macs…

    Muster 0.45.0 is installed.

    Start here:

    muster open see your skills on a page in your browser

    muster list them here in the terminal

    muster --help everything else Muster can do

    ~ %

  2. 2 Up next

    Sort them in your browser

    Muster puts your skills on one page in your browser. Your Claude Code suggests up to eight folders, then Autosort files the skills into them. The files never move, and the page never goes online.

    muster open
    127.0.0.1
    code-review brand-fontsPlugin commit-message pr-review frontend-design ui-taste
    98 skills on this Mac Muster your skills
  3. 3 Up next

    Check them with Claude Code

    Your own Claude Code reads your skills and finds the ones that conflict or repeat each other. It runs on your plan: no API key, no account. Nothing changes until you say so.

    muster check

    With a lot of skills, it can take a few minutes.

    zsh

    ~ % muster check

    Checked 98 skills with Claude Code.

    Found 2 conflicts and 6 duplicates:

    Conflict commit-message ↔ conventional-commits

    Duplicate pr-review ↔ code-review

    and 6 more

    ~ %
